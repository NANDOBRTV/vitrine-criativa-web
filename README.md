# Vitrine Criativa Web

Site institucional responsivo da agência, desenvolvido com HTML e CSS, sem dependências.

## Publicar gratuitamente

1. Abra Settings → Pages no repositório GitHub.
2. Em Build and deployment, escolha Deploy from a branch.
3. Selecione main e /(root), depois Save.
4. Aguarde a publicação em https://nandobrtv.github.io/vitrine-criativa-web/.

## Antes de divulgar

Configure o endereço comercial no link mailto da seção de contato. Atualmente o botão prepara um rascunho sem destinatário. Os preços são iniciais; domínio e hospedagem paga não estão incluídos. Não existe checkout nem envio automático de formulário.
